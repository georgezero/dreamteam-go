## The release tree

One commit follows 59676a3: the release commit. On the release tree,
every set above is unchanged except two:

What changed:
* **The session registration:** 0.12.0-dev.3 is added as batch mode
  `v0.12_dev3`, and every earlier mode is kept.
* **The session fixtures:** two files are added.
  `mini-seed52-v0123.actions.json` has the same batches as
  `mini-seed52-v0122`'s. `mini-seed52-v0123.session.json` was made from a
  clean archive of 59676a3 (0.12.0-dev.3; its engine sources are those of
  the lock commit 5b8879f) to register that build for replay.
* **The version:** `internal/version/version.go` is `0.12.0`, and
  `testdata/golden/MIGRATIONS.json` names it.

No file was removed or rewritten.

Preserved byte for byte: the simulator, llm-agent 1 to 6, every prompt
and workflow identity, the acknowledgment contract, the decision-record
contracts, the historical recordings, the frozen evidence contracts, the
golden references, the benchmark suites, the V0.10 and V0.11
experiments, the V0.12a scripted evidence, and the V0.12b locked
protocol, live run record and results. The Stage B lock's 48 pinned
files still hold. No live inference was run.
