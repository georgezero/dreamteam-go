What changed:
* **llm-agent 5** (`agents/llm/llm_agent5.py`): the `--workflow`
  selector (b44384a). `validation-first` is the default, and
  `validation-first-preview` is the V0.11a workflow, with its identity
  unchanged byte for byte. The prompts, the validation-feedback text, the
  preview message and the operations note are unchanged (hashes above).
* **The workflow identities:** `llm-agent-validation-first-workflow/v1`
  is added. `llm-agent-workflow/v1` keeps `3ee7d66f…`.
* **`analysis/repeatability`:** one file added,
  `test_workflow_selector.py`, which checks the selector against the
  V0.11b drivers. The 12 earlier files are unchanged.
* **The session registration:** 0.11.0-dev.2 is added as batch mode
  `v0.11_dev2`, and every earlier mode is kept.
* **The session fixtures:** two files are added.
  `mini-seed52-v0112.actions.json` has the same batches as
  `mini-seed52-v0111`'s. `mini-seed52-v0112.session.json` was made from a
  clean b44384a worktree (0.11.0-dev.2) to register that build for
  replay.

No file was removed or rewritten.

The historical recordings, the frozen evidence contracts, the golden
references, the benchmark suites, the V0.10 experiments, the V0.11a
scripted evidence and the V0.11b prospective evidence are preserved byte
for byte. The V0.11a scripted evidence is regenerated by CI from the
selector build and is equal to the committed files. No live inference
was rerun.
