## Decisions for the owner before Stage B

1. **F1 hardening.** Should llm-agent 6 check that each consequence field
   is present and has the documented type, withholding the proposal
   otherwise?
   * **If yes:** it is a fail-closed change that does not alter the
     contract, the acknowledgment semantics or any threshold. It does
     change the agent file, so the corrected component needs a focused
     independent re-review before live inference.
   * **If no:** the documented reliance on the engine's preview contract
     stands. The reviewer accepted that alternative.
2. **F2.** Is replay, as now documented, enough for Stage B evidence?
   * **If enough:** replay certifies the workflow's handling of recorded
     replies, and `model.jsonl` holds the model calls.
   * **If authentication of model output is wanted:** it needs a new
     mechanism, such as a keyed MAC of each raw response, decided before
     the Stage B protocol is frozen.
