Baseline: 72dc35aa7e73bccf6ca64a3857bc3d58dfabfd43 (V0.13i plus the verbatim
V0.13i independent review). The five committed independent reviews
(V0.13e–V0.13i) remain verbatim. This is implementation evidence, not the
independent technical re-review, which is PENDING. Human presentation review
is PENDING, separate, and concerns only the frozen material in
docs/v13i/human-review (ee987a1), which is unchanged. Protocol lock, live
inference and the V0.13.0 release remain NO GO.

The owner adopted "never falsely COMPLETE" with a severity hierarchy (false
COMPLETE and false acceptance of PARTIAL are release blockers; a genuine
failure safely classified INVALID is a reliability defect; a lost completed
draw or known call is a major defect) and directed that the final seal be the
only evidence of completion. The successor contract
[dreamteam.run-lifecycle/v2](../v13j/SAFETY_CONTRACT.md)
(`analysis/alternatives/lifecycle_v2.json`) was committed before any recorder
change (8b37738). The recorder (`v13j.py`) and verifier (`v13j_verify.py`)
share the contract and nothing else; the verifier does not import the
recorder.

The fault matrix is generated from the contract over nine base scenarios
covering every admissible stop code and state (and every operator safe
point); transition, stop and disposition coverage is measured from the
archives. Real SIGINT is delivered both in-process at every reached point
and from a parent process; real SIGKILL is applied at every point of the
complete base and at the stop sequences of two partial bases.

Model-visible content is unchanged: the decision workflow, parser,
presentation, view, selection, system instruction, canonicalization,
simulator, session, API and scoring are byte-identical, as are `v13h.py`
and `stage_b.py`; all 93 transcripts and 7 active static assets match the
frozen human-review manifest. The 262-draw schedule, 802-call ceiling and
primary estimand are unchanged. The engine remains 0.13.0-dev.2.

Availability limitations (rank 3, documented): a recorder fault inside the
stop, cleanup or finalization sequence (other than the session release), a
fault before an outcome record, any persistence failure, and a hard kill
before the seal each leave an unsealed INVALID archive with its durable rows
and call journal intact; there is no recovery or resumption. A SIGINT during
a model call or health read takes effect when that call returns (at most the
request timeout). Power-loss durability is not claimed.
