# V0.13l driver

`dreamteam-v13l-driver/8` wraps the unchanged V0.13h draw, engine operations, decision workflow, parser, presentation, view, selection, instruction, canonicalization and primary submitted-action estimand. Only recording, persistence and verification change. The engine version remains `0.13.0-dev.2` because mechanics, session, API, accounting and scoring are unchanged.

The successor protocol identity is `dreamteam.alternatives-experiment/v8`, experiment `v13l-alt-1`; the schedule format remains /4 with a successor protocol binding. Nine historical contexts, six sensitivity pairs, 21 contexts, two arms, 262 draws and the 802-call ceiling remain fixed. Existing recordings and all V0.13k modules retain their bytes.

The command-line `run` remains refused because the protocol is not locked. Engineering fixtures use scripted replies and scripted or localhost-only services. No inference or external model service is part of these gates.
