# V0.2 Step 0 — sustainable-practice feasibility sweep

**Question (owner decision 6, hard gate):** can the established practice
become financially sustainable using only the documented V0.2 levers —
referral demand and modality mix, technologist coverage, US slot packing,
MR coverage and radiologist reading allocation — with reimbursement, payer
behaviour, patient behaviour, exam and read durations and every expense
rate unchanged?

**Answer: no.** The best static configuration of the permitted levers
breaks even: **+0.4% operating margin over 90 days** (−0.9% to +2.4%
across 20 paired seeds). No configuration reaches a positive margin on
every seed, let alone the 6–12% band. A diagnostic beyond the documented
demand range (+50%) adds only 1–2 points, because the practice cannot
book the extra demand. The gate fails; V0.2 action code should not start
until the owner decides how the scenario changes (see *Decisions*).

All figures below come from `results/feasibility.md` (generated) and the
per-seed result files in `results/`.

## Method

* **Harness:** the calibration experiment runner
  (`internal/sim/calib_experiments_test.go`, build tag `calibration`), unchanged
  in what it measures; this pass let it read another manifest directory
  (`DT_EXP_DIR`, `DT_RES_DIR`), run manifests in parallel, and aggregate
  more of the per-seed figures it already recorded.
* **Manifests:** `experiments/*.json`, generated by `generate.py` (53
  manifests). Each is the established practice (base fingerprint
  `b1cbc2a0108f…`) plus a static JSON overlay merged by the scenario
  system's own merge; each result records the merged scenario's
  fingerprint and the overlay's SHA-256.
* **Runs:** no actions, default policies, from the takeover; windows of
  30 and 90 days. Seeds 1–9 for every manifest; the base and the three
  best candidates repeated at seeds 1–20 (`-s20`). All comparisons are
  paired by seed. Engine `0.1.0` (the released engine; this pass changes no
  engine code).
* **Report:** `report.py` writes `results/feasibility.md`: economics
  (30 and 90 days), access and utilization, report turnaround, per-seed
  profit.

Reproduce:

    python3 docs/calibration/feasibility/generate.py
    DT_EXP_DIR=../../docs/calibration/feasibility/experiments \
    DT_RES_DIR=../../docs/calibration/feasibility/results \
    go test -tags calibration ./internal/sim -run 'CalibrationExperiments$' -v -parallel 4 -timeout 600m
    python3 docs/calibration/feasibility/report.py

(The harness also writes a generic `results/summary.md`.) About 25 minutes
on a Raspberry Pi 4 for all 53 manifests.

### Levers and ranges

| Code | Lever | Values |
|---|---|---|
| `D100` `D115` `D130` | Referral demand, every source scaled | ×1.00, ×1.15, ×1.30 |
| `W115` `W130` | Referral demand, imaging-weighted (modality mix): primary and urgent care ×1.00 / ×1.10, orthopedics, OB/GYN, oncology and "other" scaled to the same total | ×1.15, ×1.30 |
| `XRCT` | XR/CT day technologist on CT, 08:00–16:30 weekdays, $38/h | added |
| `USfull` | US technologist 11:30–20:00 weekdays, $44/h (the template runs to 20:00; the US technologist leaves at 18:00) | added |
| `MRfull` | MR technologist 11:30–20:00 weekdays, $45/h (staffs the 16:30–19:30 MR slots, unstaffed today) | added |
| `P40` | US_45 slots at 40 minutes, weekday template reflowed (+1 US_45 slot a weekday) | on |
| `A55` `A50` `A65` | Radiologist site allocation (base 60% / 50%) | 55/45, 50/40, 65/55 |
| `W150` | **Diagnostic only, outside the documented range:** imaging-weighted demand ×1.50 | — |

Part-time evening shifts (e.g., 16:00–20:00) were planned but **cannot be
expressed**: scenario validation requires every shift's start plus
`maxShiftHours` (12 h) to end by midnight, so no shift may start after
12:00 (`internal/scenario/validate.go`). Evening coverage therefore costs
a full shift. This is a V0.2 design input (part-time contracts need a
per-shift or per-employee cap).

Stages: (1) each lever alone from the base; (2) staffing packages × demand
with `P40` and `A55`; (3) the same packages at the base allocation without
`P40`, plus `A65` (stage 2 showed `A55` starving reading at higher demand
and `P40` doing nothing); (4) 20-seed confirmation and the diagnostic.

## Results

### Sensitivity: one lever at a time (90 days, 9 seeds, paired)

Operating profit change per 30 days against the unchanged practice
(−$27.8k a month, margin −14.0%):

| Lever | Δ profit $k / 30 d | Margin | Main effect |
|---|---|---|---|
| Demand ×1.15 / ×1.30 | +11.5 / +19.1 | −7.6% / −3.9% | exams +8% / +14%; lost referrals 376 → 618 / 969: capacity binds |
| Imaging-weighted ×1.15 / ×1.30 | +12.1 / +19.2 | −7.3% / −3.8% | as uniform; the mix adds ≈$0.5k |
| + XR/CT technologist | −5.8 | −16.8% | lost XR/CT bookings 98 → 59, walk-ins leaving 295 → 225; costs $7.8k |
| + US evening technologist | −1.4 | −14.1% | US lost 191 → 45, +48 exams; costs $9.3k |
| + MR evening technologist | −5.1 | −16.2% | MR lost 87 → 26; too little MR demand at ×1.00 |
| US slots at 40 min | 0.0 | −14.0% | no measurable effect |
| Allocation 55/45 / 50/40 | +5.0 / +10.1 | −11.5% / −8.9% | saves salary; urgent p90 282 → 498 / 583 min, routine p90 112 → 412 / 993 min |

At the best configuration, per 30 days: net revenue ≈$245k; labor ≈$117k
(of which the two radiologists ≈$55k: $480k × (60% + 50%) × 1.25 / 12); fixed
costs $88.5k (rent $22k, MR lease and service $30k, CT lease and service
$17k, utilities, insurance, IT); variable ≈$40k. Cash at 90 days is
$79k–104k (from $150k at the takeover; receivables grow with volume);
only loss-making staffing-heavy configurations end below zero (lowest
−$25.6k).

### Service at the best configurations

Imaging-weighted ×1.30 + MR evening (20 seeds, 90 days): 790 of 5,476
referral orders lost (14%; base 9%); ≈366 walk-ins leave unseen (base
≈300, about half of all walk-ins); US lead p50 30 days; urgent breaches
≈8 over 90 days (base 15; urgent p90 ≈200 min, base 282); routine report
p90 ≈17 h (1,044 min; base 112 min): reading runs at 85% of its blocks.

Allocation cuts interact with demand: at ×1.15–×1.30 the 55/45 allocation
**collapses reporting** (routine p90 rises from hours to 1–14 days, urgent
p90 to days; reports fall behind exams). Stage-2 rows show it; they are
not candidates.

## Binding constraints

1. **Fixed costs and salaried reading are most of the cost base.** Fixed
   costs ($88.5k) and radiologist salaries (≈$55k) are ≈58% of expenses at
   the best configuration and do not scale down with volume; at ×1.3
   demand the radiologists cannot be cut either (above).
2. **Demand converts poorly into exams.** ×1.30 demand yields +14–18%
   exams; ×1.50 yields +21%. The rest is lost: patients' wait tolerance
   is exceeded (`lostDeclined`), not the 120-day horizon.
3. **The lost demand is structural, not room time.** At ×1.50, CT loses
   ≈420 referrals and XR ≈300 over 90 days while the CT and XR rooms are
   ≈40% used: CT capacity is limited by its slot template (category
   counts and times) and by the shared XR/CT technologists (Riley covers CT
   from X-ray, one exam at a time), US by its single room (≈70% of open
   time with an evening technologist) and Monday-B/Saturday gaps, MR by
   its single room. None of these is a permitted lever.
4. **Added technologists rarely pay.** An evening technologist costs
   ≈$9.3k a month; only MR recovers that at ×1.3 demand (+$6.6k
   net). US breaks even; XR/CT loses because XR exams contribute ≈$40.
5. **US packing is not a lever.** 45 → 40-minute slots add one slot a
   weekday and change nothing measurable (exams already start early into
   slack).
6. **Walk-in abandonment is large in every configuration** (≈half of
   walk-ins leave), a V0.1 behaviour that caps XR volume.

## Decisions for the owner

The gate fails under the permitted assumptions. Options, any combination:

| Option | What changes | Expected effect (from these runs) |
|---|---|---|
| A. Accept break-even | `sustainable` = imaging-weighted ×1.30 + MR evening technologist; "sustainable" means a player can reach break-even to low single digits | margin ≈0% with no actions; the 6–12% band only through play, unproven |
| B. Add CT/XR template levers | redesign the CT template (more CT_30C contrast slots, evening CT), possibly XR | targets the ≈300–400 lost CT/XR referrals at 40% room use; needs its own sweep |
| C. Revisit the cost base | e.g., MR lease/service or rent of a larger practice | each $5k a month is ≈2 margin points; this changes documented expense rates (excluded by the brief) |
| D. Revisit reimbursement or payer mix | e.g., commercial share | excluded by the brief; large effect |
| E. Teleradiology replaces part of the salaried allocation | the V0.2 contract action, priced as a real alternative | could cut fixed reading cost; requires the action, cannot be a static overlay |
| F. A second US room (capital) | equipment, V0.4 growth | US is room-bound at higher demand |

Not proposed: forcing the margin by injecting demand beyond the documented
range, slowing patients' tolerance, or lowering costs without a
documented rationale.
